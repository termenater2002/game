# Foundation v1 — исходный аудит

Проверен исходный `termenater2002/game`, а не локальный проект `MAJOR DAMAGE`.
Проект: Unity 6000.0.43f1, URP 17.0.4, ввод Both (legacy Input + Input System).
В пользовательском коде пять скриптов. Основная сцена — `Assets/Scenes/SampleScene.unity`.

## Обнаружено

- Активен Rigidbody-контроллер `FunnyMovement` (файл `Move2.cs`), альтернативный
  `PlayerMovement` (`Move.cs`) выключен. Имена трёх файлов не совпадают с классами,
  что мешает чистому импорту MonoScript после удаления старого Library.
- Прыжок читается как удержание в FixedUpdate: импульс повторяется, пока raycast видит землю.
  Скоростной лимит учитывает вертикальную скорость и мешает горизонтальному управлению в падении.
- Захват применяет силу в Update, поэтому поведение зависит от FPS. Нет демпфирования,
  точки приложения силы в месте захвата, ограничения дальности удержания и очистки состояния.
- Камера умножает сглаженные дельты мыши на deltaTime, не освобождает курсор по Escape,
  не учитывает потерю фокуса и начальный поворот тела.
- Повреждения, изменение материала, создание обломков и денежный Debug.Log смешаны.
  Нет рабочего баланса сессии и защиты от повторного разрушения/переплаты.
- В сцене два включённых Camera/AudioListener, лишние MeshCollider на камере и Volume,
  два MeshCollider на полу. Шаблон обломка — активный scene-object Cube под землёй
  с отрицательным масштабом. Есть безымянные prefab instances и корень GameObject.
- Исходные параметры: движение 8, прыжок 0.3, maxSpeed 5;
  захват 1 м / сила 10; прочность 100, пороги 3/5, стоимость 100/10000/100000.
  После удаления повторных импульсов прыжок 0.3 при массе 1 даёт подъём лишь на 4.6 мм.
  В Foundation импульс настроен на 4.2 (около 0.9 м при обычной гравитации);
  прочность, стоимость и параметры разрушения сохранены без изменений.
- Рендер/анимации: URP Volume, готовые FBX-клипы и AnimatorController;
  отдельный выключенный CharacterController-контроллер содержит настройку Speed.
- Сторонние исходники: CharacterPack Lowpoly и KayKit City Builder Bits. Сохраняются целиком.
  Пакеты Muse, Navigation, Visual Scripting и прочие исходные зависимости не обновляются.
- В Git попали 41 700 файлов Library, Logs, UserSettings, сгенерированные csproj/sln.
  Действующий .gitignore содержит только `game.git/`.

## План реализации

1. Исключить генерируемые файлы из индекса без удаления локальных файлов.
2. Разложить собственные ресурсы по назначению; переносить вместе с .meta, не менять GUID.
3. Исправить ввод/физику, курсор и захват; сохранить выбранный контроллер и параметры.
4. Выделить состояние прочности и расчёт урона, добавить простой кошелёк сессии и HUD.
5. Минимально почистить сцену, добавить полезные EditMode/PlayMode проверки.
6. Проверить реальный Editor и оформить README, ARCHITECTURE, CHANGELOG, NEXT_STEPS.

## Версия для проверки

На машине установлен только 6000.6.8f1. По ответу пользователя новая версия не устанавливается.
Реальный запуск проверяется в отдельной копии на 6000.6.8f1. В основной ветке остаются
6000.0.43f1 и исходные пакеты; автосохранённые сцены/настройки новой версии не переносятся назад.
Запуск на точной исходной версии не считается проверенным.
