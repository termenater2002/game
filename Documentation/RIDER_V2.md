# Rider V2 — low-poly street rider

Новая модель построена в Blender 5.3 и подключена в SampleScene и AnimationPreview.
Сохранён парень в закрытом спортивном шлеме, без Z, с длинными ногами и стройной
комплекцией. Свободная куртка, широкие брюки, перчатки и ботинки имеют собственную
геометрию; торс с рукавами и брюки с тазом — соединённые поверхности.

Стиль: плоские грани, крупные складки, простые цвета, без подразделения поверхности
и процедурной мелкой фактуры ткани. У шлема настоящий вырез под отдельный визор,
выступающая подбородочная часть, вентиляция, боковые шарниры и задний спойлер.

Unity: **7004 треугольника**, один SkinnedMeshRenderer, 13 материалов URP Lit,
22 кости, валидный Humanoid Avatar. Blender считает 7028 треугольников до очистки
вырожденных граней при FBX-импорте. Число вершин Unity выше из-за разрывов нормалей
между плоскими гранями. Импорт сохраняет авторские нормали.

Файлы:

- `ArtSource/RiderV2/RiderV2.blend` — редактируемый Blender-исходник с отдельными
  деталями, скелетом, расслабленной демонстрационной позой и студийным светом.
- `ArtSource/RiderV2/RiderV2_Front.png` — реальный рендер Blender.
- `ArtSource/RiderV2/build_rider_v2.py` — авторский источник геометрии. Для другого
  рабочего каталога измените переменную `P` перед запуском. Скрипт создаёт отдельную
  сцену и экспортирует нейтральную T-позу; демонстрационная поза в FBX не запекается.
- `Assets/Game/Characters/RiderV2/RiderV2.fbx` и `RiderV2.prefab` — игровые ассеты.
- `AgentScripts/ImportRiderV2.cs` — повторяемая настройка Humanoid, материалов и
  подключения визуального корня через живой Unity Editor.

Существующие `Characters/Rider`, сторонние модели и исходные анимации сохранены.
Физический родитель, капсула, масса, управление и FPS-камера не менялись.
Размер импорта 1.75 под существующий масштаб игрока 0.1. Root Motion выключен;
ранее исправленное извлечение XZ у движущихся клипов сохранено.
F6 включает боковую камеру, F7 меняет сторону. В FPS тело продолжает отбрасывать
настоящую анимированную тень через ShadowsOnly.

При проверке исправлены направление Humanoid относительно геометрии и веса
внутренних краёв широких штанин и строчки: они больше не цепляются за другую ногу.
Имена экспортируемого скелета стабильны при повторной сборке.

Проверено в запущенном Unity **6000.6.8f1**, в рабочей проверочной копии проекта:
**15 EditMode + 15 PlayMode passed**. Проверки используют новый prefab, проверяют
бюджет до 10 тысяч треугольников, веса, направления костей, движение и циклы назад,
прыжок/падение/приземление, боковую камеру и сохранение shadow pass в FPS.
Контрольные кадры реальной основной сцены находятся в `RiderUpdate/`.
После увеличения объёма рук футболки повторно прошли все 5 её PlayMode-проверок.
Проверки движения, прыжка, обратной ходьбы и shadow pass выполняются отдельно
для куртки и футболки; оба варианта обнаружены PlayMode runner и реально выполняются.
Финальная консоль: 0 ошибок, 0 предупреждений, компиляция успешна.

ProjectVersion 6000.0.43f1 и пакеты исходного репозитория не менялись. Проверка
в точной исходной версии Editor и standalone-сборка не выполнялись. Editor оставлен
в Edit Mode основной сцены; временные Auto Tick и Run In Background выключены.

Исправлены пересечения куртки со светлыми панелями и подкладкой. Панели теперь
назначены материалом на грани единой поверхности; отдельных накладок и скрытого
полного торса под курткой нет. Швы, карманы и молния проецируются на реальную
поверхность куртки и наследуют веса её треугольников. Подол вынесен за пояс брюк,
манжеты разведены с концами рукавов.

Добавлена отдельная версия **RiderV2TShirt**: короткие рукава, открытые предплечья,
светлая футболка. Руки имеют более ровный профиль: умеренная толщина у плеча,
выраженное предплечье и полное запястье с подогнанным краем перчатки. У обеих
версий увеличены ладони и пальцы: длина на 30%, ширина ладони до 22%, с сохранением
посадки у запястья. Unity: **6276 треугольников**, 14 материалов, те же 22 кости и
тот же контроллер анимаций. Файлы находятся в `Assets/Game/Characters/RiderV2TShirt`
и `ArtSource/RiderV2TShirt`. В общей Blender-сборке выберите `OUTFIT = 'tshirt'`.
Футболка не заменяет куртку в основной сцене.

Для просмотра откройте **Assets/Game/Scenes/AnimationPreviewTShirt.unity** и нажмите
Play. 1–8 выбирают анимацию, P включает автоматический цикл. Куртка остаётся
в SampleScene и AnimationPreview. Реальные кадры обеих версий в движении сохранены
в `RiderOutfits/Jacket` и `RiderOutfits/TShirt`.

Импортёр повторно считывает нормализованную Humanoid-позу после первичного
FBX-импорта: иначе первый импорт Generic-позы мог раздувать humanScale. Масштаб
обеих готовых Avatar равен 1.89528167; его пропорция относительно модели проверяется.

Повторный импорт в открытом проверочном проекте:

```bash
unity command script run --file AgentScripts/ImportRiderV2.cs --entry ImportRiderV2.Import --project-path /path/to/project --caller plugin --skill unity-pipeline
unity command script run --file AgentScripts/ImportRiderV2.cs --entry ImportRiderV2.ImportTShirt --project-path /path/to/project --caller plugin --skill unity-pipeline
unity command script run --file AgentScripts/ImportRiderV2.cs --entry ImportRiderV2.ApplyToMainScene --project-path /path/to/project --caller plugin --skill unity-pipeline
```

ApplyToMainScene выполняйте в Edit Mode с открытой SampleScene. Готовый prefab и сцены
уже сохранены; обычное открытие проекта не требует повторного запуска генераторов.
