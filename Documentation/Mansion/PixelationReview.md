# Пикселизация особняка

Включена для Main Camera и Side Test Camera (F6). Scene View и камеры без компонента PixelationCamera сохраняют обычный вид. ScreenSpaceOverlay HUD рисуется после фильтра и остаётся в разрешении экрана.

Настройка: выбрать камеру → Pixelation Camera → Vertical Pixels. Значение 180 даёт блоки 4×4 при 1280×720 и 6×6 при 1920×1080. Меньшее значение делает пиксели крупнее. Снятие флажка компонента отключает эффект на этой камере. Размер блока округляется до целого числа физических пикселей, частичный блок у границы кадра допустим.

## 1. Validation Summary

Проверено по навыку validate-urp-render-graph-renderer-feature и реальными кадрами Unity 6000.6.8f1. Чёткая квадратная сетка подтверждена измерением исходных PNG: 100% проверенных блоков мира одноцветны, белые штрихи HUD сохранились на 100%. При 1280×720 проверены блоки 4×4. См. pixelation_proof.json, [включено](Pixelation_On.png), [выключено](Pixelation_Off.png), [боковая камера](Pixelation_Side.png).

## 2. Confirmed Issues

В итоговой реализации проблем с привязкой материала и ресурсов не обнаружено. Первоначально общая игровая сборка не ссылалась на URP; фильтр вынесен в отдельную MajorDamage.Rendering со ссылками Core.Runtime и Universal.Runtime. После исправления ошибок компиляции нет.

Инструмент Pipeline при захвате камеры вместе с overlay UI рендерит в размере Game View и затем масштабирует в запрошенный размер. Проверка HUD выполнена в исходном размере 1107×627, без этого масштабирования. Дополнительно выполнен независимый рендер мира 1280×720 без overlay. Сам фильтр не применяет размывание.

## 3. Likely Issues / Risky Assumptions

Реальный запуск выполнен в установленном Editor 6000.6.8f1. Наличие используемых API также сверено с локальными исходниками URP/Core 17.0.4 исходного проекта; запуск Editor 6000.0 не выполнялся. Реализация рассчитана на Render Graph; режим Compatibility Mode и XR отдельно не проверялись. Последующее масштабирование окна или изображения внешними средствами может сгладить пиксели.

## 4. Recommended Fixes

Дополнительных обязательных исправлений для текущего проекта нет. Для скриншотов с HUD использовать собственное разрешение Game View. Для другого желаемого размера пикселя менять Vertical Pixels на обеих игровых камерах. Новым камерам эффект подключается добавлением PixelationCamera.

## 5. Corrected Implementation

- Shader сериализован в Renderer Feature, поэтому сохраняется ссылкой при сборке. Временный материал уничтожается в Dispose/Create.
- Source — activeColorTexture, destination — отдельная graph-текстура с производным дескриптором. Чтение и запись не используют один ресурс.
- AddBlitPass явно связывает отслеживаемый source с _BlitTexture. MaterialPropertyBlock хранит параметры отдельно для каждой камеры.
- После прохода resources.cameraColor указывает на результат. Глобальные текстуры не публикуются.
- requiresIntermediateTexture обеспечивает читаемый цветовой буфер; проверки IsValid/backbuffer предотвращают неподдерживаемое чтение. Opaque/depth/normals входы не запрашиваются: они не используются.
- Проход AfterRenderingPostProcessing выполняется до overlay HUD. UV округляются к центру целого квадратного блока, семплер PointClamp; сглаживание камер выключено.
- PC_Renderer и Mobile_Renderer получили только новую feature, их прочие исходные настройки сохранены. В камерах других сцен компонента нет, поэтому эффект там не включается.

## 6. Missing Information

Для текущей сцены отсутствующих данных нет. Проверки XR/Compatibility Mode и отдельного Player build не входят в выполненную проверку редактора.

Исходники: Assets/Game/Scripts/Rendering, Assets/Game/Shaders/Pixelation.shader. Повторное подключение: InstallPixelation.Apply через unity command script run; автоматический сборщик особняка также создаёт настройки камер. Проверка: ArtSource/Mansion/verify_pixelation.py. Проверка временно меняет камеру/ввод тестовой сцены; после неё остановить Play и выполнить MansionFinalize.Restore. Редактор уже возвращён в чистую сохранённую сцену с нормальным управлением и включённым фильтром.

Текущие ошибки/предупреждения — 0: pixelation_final_console.json / groundTruth. Счётчики counts содержат историю буфера за всю сессию, включая ранее исправленные ошибки.
